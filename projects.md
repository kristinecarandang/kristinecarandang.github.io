# Projects

A selection of test automation projects covering UI, API, and mobile testing across different frameworks and stacks.

---

### [Swag Labs UI Test Automation](https://github.com/kristinecarandang/KC-TestAutomation_swaglabs)
**Stack:** TypeScript · Playwright · GitHub Actions

End-to-end UI test suite for the Swag Labs e-commerce demo app, built with Playwright and TypeScript. Includes a CI pipeline configured via GitHub Actions so tests run automatically on every push, and example test patterns for structuring larger suites.

---

### [API Test Automation (Postman)](https://github.com/kristinecarandang/KC_TestAutomation_API)
**Stack:** Postman

A collection of Postman-based API tests demonstrating request validation, response assertions, and organized test collections for REST API coverage.

---

### [The Dog API — Playwright API Tests](https://github.com/kristinecarandang/api-TheDog)
**Stack:** JavaScript · Playwright

API testing suite for The Dog API, using Playwright's API testing capabilities to validate endpoints, response schemas, and status codes outside of a browser context.

---

### [Mobile E2E Testing with Detox](https://github.com/kristinecarandang/DetoxTestApp)
**Stack:** React Native · Detox · Jest

A React Native app configured with Detox for end-to-end mobile test automation on iOS and Android, alongside Jest for unit-level tests — demonstrating a full mobile testing setup from app scaffold to E2E test runner.
